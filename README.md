# shen-202610.github.io

二建机电 · 分章节刷题（PWA，可离线使用）

- 题库依据 2024 版二级建造师考试用书《机电工程管理与实务》知识点编写，共 **90 题**（单选 + 多选）
- 章节结构：
  - 第一章 机电工程常用材料及设备：1.1 常用材料（24 题）、1.2 常用设备（14 题）、1.3 建设工程基本法律制度（法规·法律部门和法律体系、法的形式和效力层级，16 题）
  - 第二章 机电工程专业技术：2.1 机电工程测量技术（12 题）、2.2 机电工程起重技术（12 题）、2.3 机电工程焊接技术（12 题）
- 功能：分节解锁刷题、整节答完后统一评分与逐题解析；练题模式每题即时判对错、错题自动收录进错题本并支持重练、Service Worker 离线缓存
- 刷题进度与错题保存在浏览器本地（localStorage 键 `erjian_v2`），重开页面自动恢复
