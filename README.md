# shen-202610.github.io

二建机电 · 分章节刷题（PWA，可离线使用）

- 题库依据 2024 版二级建造师考试用书《机电工程管理与实务》知识点编写，共 **90 题**（单选 + 多选）
- 章节结构（按湖南二建考试科目编排，全部小节自由开放）：
  - 机电工程管理与实务（实务）：1.1 常用材料（24 题）、1.2 常用设备（14 题）、2.1 测量（12 题）、2.2 起重（12 题）、2.3 焊接（12 题）
  - 建设工程法规及相关知识（法规）：1.3 法律部门和法律体系、法的形式和效力层级（16 题）
- 功能：整节答完后统一评分与逐题解析；练题模式每题即时判对错、错题自动收录进错题本并支持重练（连续答对 3 次自动移除）；做题记录（记忆功能）：每次作答自动记录，可查看统计与明细；Service Worker 离线缓存
- 刷题进度、错题与做题记录保存在浏览器本地（localStorage 键 `erjian_v2`），重开页面自动恢复
